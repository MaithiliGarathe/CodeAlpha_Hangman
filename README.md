# 🎮 Hangman Game

A simple command-line **Hangman Game** developed using Python as part of the **CodeAlpha Python Programming Internship**.

The game challenges the player to guess a hidden word one letter at a time. The player has a limited number of incorrect attempts before the game ends.

## 🚀 Features

- 🎯 Random word guessing
- 🔤 Guess the word one letter at a time
- ❤️ Limited number of attempts
- ✅ Displays correctly guessed letters
- ❌ Tracks incorrect guesses
- 🏆 Shows the final result
- 🖥️ Simple command-line interface

## 🛠️ Technologies Used

- Python
- Random module
- Loops
- Conditional statements
- Lists
- Strings
- User input
